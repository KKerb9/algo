# Поправки к источникам и найденные при проверке ошибки

Все численные и формульные факты из `facts/*.tex` проверены скриптами `tests/facts/*.py`
(перебор малых случаев, точные дроби, сравнение с независимой реализацией). Здесь только то,
что **не совпало** с источником или потребовало уточнения. В PDF исправленные места помечены `†`.

## Ошибки / неточности в образцах

| Где | Было | Стало | Как проверено |

## Уточнения (в источнике верно, но неполно)

* Период Пизано `<= 6m`; равенство достигается ровно при `m = 2*5^k`, `k >= 1` (`m=2` не подходит: `pi(2)=3`).
* Кирхгоф в нотации образцов (`L[u][v]-=1, L[v][v]+=1`): минор даёт остовы, направленные **от** корня;
  в BEST нужны деревья, направленные **к** корню (`L[u][u]+=1`). Для эйлерова орграфа числа совпадают.
* Нараяна: «деревья с `n` рёбрами и `k` листьями» -- плоские корневые (упорядоченные) деревья.
* Формулы с `(a,b,c,d)` для четырёхугольника и Герона проверены на случайных многоугольниках, но условия
  существования (выпуклость, вписанность) остаются на вызывающем коде.

## Ошибки моих черновиков, пойманные проверкой

* Мизер-ним: при всех кучах `<= 1` первый выигрывает при **чётном** числе единиц (я написал «нечётном»).
* Кайлс: период 12 начинается с `n = 71` (последнее исключение -- `n = 70`), а не «около 70».
* Описанная окружность в `geoma/point2d.cpp`: перепутан знак центра -- найдено стресс-тестом `tests/geo.cpp`.
* Ро-Поллард (`math/prime.cpp`) зацикливался на малых составных (все простые делители закрывали цикл в одном
  блоке из 64 шагов) -- найдено `tests/m_numth.cpp`, исправлено откатом и пошаговым gcd.
* NTT (`opts/ntt.cpp`): при свёртке по произвольному модулю входы не приводились по модулю простого -- переполнение `int`.

## Что не проверялось численно

Классические теоремы без численного содержания приведены по образцам (встречаются минимум в двух источниках):
Брукс, Визинг, Менгер, Куратовский / границы `E <= 3V-6`, `E <= 2V-4`, Дирак/Оре, стабильные паросочетания,
