# Stay Hard -- team book (ICPC-формат)

Командный справочник: код на C++ + раздел фактов без кода. Каждый алгоритм из `CONTENTS.md`
имеет стресс-тест против брутфорса, каждое численное утверждение раздела фактов проверено скриптом.

## Структура

| Путь | Что |
|---|---|
| `tmp.cpp`, `tmpFast.cpp`, `alloc.cpp`, `cmp.sh`, `stress.sh` | шаблон и вспомогательные скрипты |
| `dataStructures/` | Фенвик, спарс, ДО (ленивое и снизу), СНМ с откатами, декартовы деревья, LCT, КХТ, Mo |
| `graphs/` | паросочетания (потоки -- в репозитории, из книги убраны), SCC/2-SAT, мосты, HLD/центроиды, пути, динамическая связность |
| `math/` | теория чисел, простые, Гаусс, рекурренты, комбинаторика, симплекс |
| `opts/` | NTT/FFT/FWHT, многочлены, оптимизации ДП |
| `strings/` | Z, префикс, Манакер, суфмас, автомат, Ахо-Корасик, эертри, хеш |
| `geoma/` | `point2d.cpp` (база `mpt/mln/mcr`), `polygon.cpp` |
| `other/` | pbds, хеш, быстрый ввод, int128 |
| `facts/` | разделы фактов (`*.tex`), `war.tex` -- памятка «затуп / баг / не сдаваться», `ERRATA.md` -- найденные расхождения с источниками |
| `tests/` | стресс-тесты (`*.cpp`), `run_all.sh`, `facts/*.py` -- проверка фактов |
| `tools/build_book.py`, `tools/preamble.tex` | сборка PDF |
| `CONTENTS.md` | что входит в книгу, приоритеты, решения по объёму |

Стиль: `#include "tmp.cpp"` в начале файла, отступ 8 пробелов, `ve/vi/ll/ld`, `all(x)`, `chmin/chmax`, имена в стиле
репозитория. Для сборки книги `#pragma once` и локальные `#include` вырезаются (зависимости остаются как `// + файл`).

## Как собрать PDF

Нужны `python3` и LaTeX (`pdflatex` с `babel`, `listings`, `multicol`, `titlesec`, `fancyhdr`; в Ubuntu:
`apt install texlive-latex-base texlive-latex-extra texlive-fonts-recommended texlive-lang-cyrillic texlive-science`).

```bash
python3 tools/build_book.py            # шрифт 8pt, 3 колонки, A4 landscape
python3 tools/build_book.py --font 7   # плотнее
```

Результат: `output/pdf/algo-teambook.pdf` (и `.tex`). Состав берётся из таблицы в `CONTENTS.md` (`status = in`).
Если книга не влезает в 25 страниц -- поставить `cut` у наименее приоритетных строк и записать решение в конец `CONTENTS.md`.

## Как запустить тесты

```bash
./tests/run_all.sh                 # все стресс-тесты + проверка фактов
./tests/run_all.sh geo m_numth     # только выбранные
JOBS=8 TEST_TIMEOUT=300 ./tests/run_all.sh
```

Тест = `tests/<имя>.cpp`: подключает `tests/common.h` (шаблон без его `main`, генератор `rnd`, `CHECK/CHECK_EQ`),
включает библиотечные файлы и гоняет сотни--тысячи случайных малых случаев против брутфорса. Компиляция идёт с
`-fsanitize=address,undefined -D_GLIBCXX_DEBUG`. Упавший тест не удалять -- чинить код (так найдено 5 настоящих багов,
см. `facts/ERRATA.md`). Факты: `python3 -I tests/facts/<имя>.py` (нужен `numpy` только для `game_prob.py`).

## Допущения и ограничения

* Компилятор: g++ >= 13, C++20 (шаблон `cmp.sh` использует `-std=c++23` и путь Homebrew -- на Linux заменить на `g++`).
* В `tmp.cpp` добавлены `#pragma once` и `using pll = pair<ll, ll>;`; остальное не менялось. `main` шаблона глушится в тестах `#define main`.
* Геометрия: единый код для `ld` (`pt`) и `ll` (`ipt`); `sgn` сравнивает с `eps = 1e-9`, для целых это точное сравнение.
  Предикаты (`hull`, `pip`, `segInter`, `minkowski`) выдают точный результат на `ipt` с координатами до ~1e9.
* Старый «сырой» код (решения задач с `main`, `mincockskii`, пустой `hld.cpp`) заменён библиотечными версиями; удалённое есть в истории git.
* Рекурсивные DFS (SCC, мосты, HLD, центроиды) рассчитаны на `ulimit -s unlimited` при глубине порядка 1e6.
* Модули по умолчанию `MOD = 1e9+7` (комбинаторика, Гаусс по модулю, линейные рекурренты) и `998244353` (NTT, многочлены).
* Образцы: KACTL и Muffix Sassif TRD (клонированы с GitHub), teambook учителя (`MrBruceVVayne/teambook`), страницы
  `mangooste.ru/lib/algo` (комбинаторика) и ProofWiki «Properties of Binomial Coefficients» (использован как чек-лист
  биномиальных тождеств -- все проверены). Тексты фактов переписаны, дубли объединены.
* Не реализовано (см. `CONTENTS.md`): пересечение матроидов, суффиксное дерево, Делоне, 3D-оболочка, Min25.
* Пуш в `KKerb9/algo` из облачной сессии отклоняется (нет доступа GitHub App) -- коммиты лежат локально в ветке `main`.

## Правила НЕФ для TRD (чек-лист)

Источник: [Team Reference Documents at Northern Eurasia Finals](https://nerc.icpc.global/information/team-reference.html).

| Требование | Как выполнено |
|---|---|
| Одна печатная копия, до 25 страниц, A4, односторонняя печать | сейчас 25 страниц, A4 landscape |
| Номер страницы в правом верхнем углу **каждой** страницы | `fancyhdr`, включая обложку |
| В левом верхнем углу: университет и фамилии по алфавиту, например `ITMO University (Ivanov, Petrov, Sidorov)` | шапка задана по умолчанию в `tools/build_book.py`; другая -- `--team "University (Surname1, Surname2, Surname3)"` (по-английски: кириллица в шапке не поддерживается) |
| Читаемо без увеличения с 50 см (минимального кегля нет) | код 8pt, факты 9pt, ничего мельче 7pt |
| Без рукописных правок | печатать после финальной сборки, ничего не дописывать ручкой |
| Без «неприемлемого текста и изображений» (решает жюри) | `python3 tools/build_book.py --clean` -> `algo-teambook-clean.pdf` без мата; печатать **его** на проверку |
| Прозрачная папка (file/punched pocket) | физически, не в PDF |
| Сдача на регистрации, проверка до практики, правки -- не более часа после практики | организационно |

Если жюри вернёт TRD с замечаниями, есть час после практики: пересобрать (`--team`, `--clean`) и сдать заново.
